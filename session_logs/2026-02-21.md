# Session 2026-02-21 — Initial Prototype

## What
iPhone-as-trackpad for Mac over USB cable. Built from scratch in one session.

## Architecture
- **iPhone app** (`PhoneTrackpad/`): Full-screen touch capture surface, TCP server on port 8765 via NWListener
- **Mac CLI** (`MacReceiver/`): Swift Package executable, connects via iproxy USB tunnel, gesture recognition → CGEvent injection
- **Transport**: `iproxy 8765:8765` (libimobiledevice) tunnels TCP over USB cable. Sub-ms latency.
- **Protocol**: Newline-delimited JSON (`{"touches":[{"id":0,"x":0.5,"y":0.3,"phase":"moved"}]}`)

## Decisions

### Phone as TCP server, Mac as client (via iproxy)
- iproxy only forwards Mac→Device, so phone must be the server
- Initial attempt had rapid connect/disconnect loop — iproxy probe connections were triggering `newConnectionHandler` which cancelled the real connection each time
- **Fix**: Guard against connection replacement if existing connection is `.ready`; single reconnect path on Mac side with `isReconnecting` flag

### UIKit AppDelegate instead of SwiftUI App lifecycle
- Needed `preferredScreenEdgesDeferringSystemGestures` which only works on root UIViewController
- UIHostingController doesn't reliably expose this override
- **Fix**: Plain `EdgeLockContainerController` wraps UIHostingController, returns `nil` for `childForScreenEdgesDeferringSystemGestures`
- Note: Horizontal bottom-edge swipe (quick app switch) can't be deferred — iOS limitation. Guided Access is the nuclear option.

### Sensitivity sent from phone to Mac
- Settings overlay on phone with X/Y sensitivity sliders (persisted via @AppStorage)
- Sent as `{"type":"settings","sensX":1.0,"sensY":1.0}` control messages over same TCP channel
- Mac applies per-axis multiplier before acceleration curve

### xcodegen for iOS project
- Avoids committing .xcodeproj noise
- `project.yml` → `xcodegen generate` → build
- Team ID hardcoded (53SVPQ672T) for CLI deployment

## Features Working
- 1-finger move → cursor movement (with acceleration curve)
- 1-finger tap → left click
- 2-finger tap → right click
- 2-finger drag → scroll (natural direction, with momentum)
- X/Y sensitivity sliders (phone UI, sent to Mac)
- Lock mode (defers system edge gestures)
- Landscape support
- Auto-reconnect on app foreground
- Screen stays awake

## Known Limitations
- Quick app switch (horizontal bottom swipe) can't be deferred
- No drag gesture (click-hold-move) yet
- No pinch/zoom
- No three-finger gestures (Mission Control etc — needs private APIs)
- Scroll momentum decay is fixed (0.92/frame), not tunable from phone

## Tech Notes
- `xcrun devicectl device install app` + `device process launch` for CLI deployment
- Developer Mode must be enabled on phone + developer profile trusted
- Mac needs Accessibility permissions for CGEvent injection
- `setbuf(stdout, nil)` needed for unbuffered output through `swift run` pipe
